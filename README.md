# M&S CONSULTORIA — Purple Team Cybersecurity Website

Website corporativo de alta conversão e estética cibernética avançada desenvolvido para a **M&S CONSULTORIA**, especializado em **Purple Team Cybersecurity & Threat Intelligence**.

Inspirado na arquitetura tática visual com núcleo neural 3D interativo, agora reimaginado sob a **identidade visual Purple Team**: a fusão perfeita entre **Red Team (Ataque / Crimson)** e **Blue Team (Defesa / Cyber Blue)** convergindo em **Purple / Violeta Elétrico**.

---

## 🛡️ Destaques e Funcionalidades

1. **Paleta Purple Team Genuína**:
   - Roxo elétrico, violeta profundo, magenta neon, combinados harmoniosamente com acentos em vermelho ofensivo e azul defensivo.
2. **Núcleo Neural 3D Interativo (Neural Core)**:
   - Órbitas rotativas tridimensionais (Vetor Red, Vetor Blue e Matriz Purple).
   - Efeito físico de **implosão (ao segurar o clique)** e **explosão tática de pulso (ao soltar)**.
   - Emblema vetorial corporativo estilizado da **M&S Consultoria**.
3. **Rede de Partículas Interativa (`particles.js`)**:
   - Conexões dinâmicas que reagem ao mouse em tons de roxo, azul ciano e vermelho.
4. **Console de Telemetria Tática Interativo**:
   - Terminal simulado com comandos e testes de cenários reais (Ransomware Detection, Lateral Movement, Cloud Breach e mitigação Sigma/EDR).
5. **Feedback Sonoro Cibernético Opcional**:
   - Sintetizador sonoro integrado via **Web Audio API** (sem arquivos de áudio externos para carregar).
6. **Planos & Pacotes Comerciais**:
   - *Purple Assessment* (Avaliação Inicial)
   - *Purple Continuous Shield* (Monitoramento & Validação Contínua)
   - *Enterprise Sovereign* (Retainer Crítico / CISO Advisory)
7. **Modal de Diagnóstico & Canais Criptografados**:
   - Agendamento de diagnóstico rápido integrado ao WhatsApp corporativo e formulário de solicitação.
8. **Responsividade Total**:
   - Adaptável para computadores, tablets e smartphones.

## 🚀 Como Visualizar e Testar Localmente

Basta dar um duplo clique no arquivo `index.html` ou executar no terminal PowerShell:

```powershell
Start-Process "C:\Users\Admin\.gemini\antigravity\scratch\ms-consultoria-purple-team\index.html"
```

Caso queira rodar um servidor HTTP local simples:
```powershell
cd C:\Users\Admin\.gemini\antigravity\scratch\ms-consultoria-purple-team
python -m http.server 8080
```
E acesse no navegador: `http://localhost:8080`

## 🌐 Como Publicar para seus Clientes

1. **GitHub Pages (Gratuito)**:
   - Crie um repositório no seu GitHub (ex: `ms-consultoria-site`).
   - Faça upload do `index.html`.
   - Em *Settings -> Pages*, selecione o branch `main` e salve. Seu site ficará ativo instantaneamente em `https://seu-usuario.github.io/ms-consultoria-site/`.
2. **Vercel ou Netlify (Gratuito)**:
   - Arraste a pasta `ms-consultoria-purple-team` para o dashboard do Netlify ou conecte via Vercel CLI / Git.
